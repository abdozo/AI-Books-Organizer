# منظم الكتب

تطبيق ويب محلي لفهرسة مجموعة من كتب PDF العربية باستخدام Gemini. يفتح في المتصفح، لكن الخادم والملفات وقاعدة البيانات تعمل على جهازك.

## ما الذي يجب تثبيته؟

يحتاج الجهاز إلى Python 3.11 أو أحدث فقط. لا يحتاج المستخدم إلى تثبيت FastAPI أو بقية مكتبات Python يدويًا، ولا يحتاج إلى Node.js أو خادم قاعدة بيانات. ينشئ ملف التشغيل بيئة محلية داخل مجلد `.venv`، ثم يثبت الحزم الموجودة في `requirements.txt` عند أول تشغيل.

يحتاج التشغيل الأول إلى اتصال بالإنترنت لتنزيل الحزم. يحتاج فحص الكتب إلى اتصال بالإنترنت ومفتاح Gemini API، أما واجهة التطبيق وقاعدة SQLite وملفات PDF فتعمل محليًا.

## التشغيل على Windows

1. ثبّت [Python](https://www.python.org/downloads/windows/) بإصدار 3.11 أو أحدث إذا لم يكن موجودًا. فعّل خيار `Add python.exe to PATH` أثناء التثبيت.
2. انسخ مجلد التطبيق كاملًا إلى الجهاز، لكن لا تنسخ مجلد `.venv` من جهاز آخر.
3. انقر نقرًا مزدوجًا على `Start-Books-Organizer.bat`.
4. انتظر حتى ينتهي تنزيل الحزم في أول تشغيل. يفتح التطبيق في المتصفح تلقائيًا.

ملفات التحكم على Windows:

- `Start-Books-Organizer.bat` يشغل التطبيق.
- `Stop-Books-Organizer.bat` يوقفه.
- `Restart-Books-Organizer.bat` يعيد تشغيله.

إذا عرض Windows تحذير SmartScreen، شغّل الملف فقط إذا حصلت على نسخة التطبيق من مصدر تثق به.

## التشغيل على macOS

1. افتح Terminal ونفّذ `python3 --version`. إذا كان الإصدار أقدم من 3.11 أو لم يعمل الأمر، ثبّت [Python](https://www.python.org/downloads/macos/) بإصدار 3.11 أو أحدث.
2. انسخ مجلد التطبيق كاملًا إلى الجهاز، لكن لا تنسخ مجلد `.venv` من جهاز آخر.
3. انقر نقرًا مزدوجًا على `Start-Books-Organizer.command`.
4. انتظر حتى ينتهي تنزيل الحزم في أول تشغيل. يفتح التطبيق في المتصفح تلقائيًا.

ملفات التحكم على macOS:

- `Start-Books-Organizer.command` يشغل التطبيق.
- `Stop-Books-Organizer.command` يوقفه.
- `Restart-Books-Organizer.command` يعيد تشغيله.

إذا رفض macOS فتح الملف في المرة الأولى، انقر عليه بزر الفأرة الأيمن واختر `Open`. إذا ظهرت رسالة بأن الملف غير قابل للتنفيذ، افتح Terminal داخل مجلد التطبيق ونفّذ:

```sh
chmod +x Start-Books-Organizer.command Stop-Books-Organizer.command Restart-Books-Organizer.command
```

يعمل الخادم في الخلفية على Windows وmacOS، لذلك لا تحتاج نافذة Command Prompt أو Terminal إلى البقاء مفتوحة.

يفتح التطبيق عادة على `http://127.0.0.1:8765`. إذا كان المنفذ مشغولًا يختار أول منفذ متاح حتى `8774`. يسجل التطبيق المنفذ الحالي داخل `data/server.json` حتى تستطيع أوامر الإيقاف وإعادة التشغيل الوصول إلى النسخة الصحيحة.

يمكن أيضًا التحكم في الخادم من الطرفية بعد تشغيل التطبيق مرة واحدة وإنشاء `.venv`.

على Windows، من داخل مجلد التطبيق:

```bat
.venv\Scripts\python.exe server_control.py start
.venv\Scripts\python.exe server_control.py stop
.venv\Scripts\python.exe server_control.py restart
.venv\Scripts\python.exe server_control.py status
```

على macOS، من داخل مجلد التطبيق:

```sh
.venv/bin/python server_control.py start
.venv/bin/python server_control.py stop
.venv/bin/python server_control.py restart
.venv/bin/python server_control.py status
```

## نقل التطبيق إلى جهاز آخر

- انسخ ملفات المشروع و`requirements.txt`، واترك ملف التشغيل ينشئ `.venv` جديدًا على الجهاز الآخر.
- انسخ مجلد `data` إذا أردت نقل الكتب والفهرس والإعدادات الحالية.
- لا تنسخ مجلد `data` عند توزيع نسخة فارغة على مستخدم آخر. يحتوي ملف `data/library.sqlite3` على مفتاح Gemini المحفوظ والبيانات المفهرسة.

## طريقة الاستخدام

1. افتح الإعدادات، ثم أدخل مفتاح Gemini واختر النموذج واحفظهما.
2. اختر ملف PDF واحدًا أو مجلدًا يحتوي على عدة ملفات.
3. حدد أقصى عدد من الصفحات التي يفحصها التطبيق لكل كتاب.
4. راجع النتائج من صفحة الكتب. تشمل البيانات سنة النشر ورقم الطبعة ورقم المجلد، ويمكنك تعديل الحقول أو إعادة فحص الكتاب.
5. استخدم صفحات المؤلفين والمحققين ودور النشر والموضوعات لدمج الأسماء أو إعادة تسميتها.

## مخطط استجابة Gemini

يعرف الخادم مخطط JSON في `organizer/models.py` ويرسله إلى Gemini عبر `response_json_schema`. لا يضع التطبيق المخطط داخل الـPrompt، ولا يعرضه ضمن الإعدادات أو يقبله من واجهة API. يستطيع المستخدم تعديل تعليمات الاستخراج فقط.

## البيانات والخصوصية

- يحفظ التطبيق نسخ PDF وقاعدة SQLite داخل مجلد `data`.
- يحفظ التطبيق مفتاح Gemini داخل جدول `settings` في `data/library.sqlite3` كنص محلي عادي. لا يعيد المفتاح إلى واجهة المتصفح بعد حفظه.
- لا يرسل إلى Gemini إلا صفحات الكتب التي يختار المستخدم فحصها.
- يستمع الخادم إلى `127.0.0.1` فقط، لذلك لا يكون التطبيق متاحًا لأجهزة الشبكة الأخرى.
